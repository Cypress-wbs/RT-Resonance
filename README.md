# RT-Resonance
2026年嵌入式芯片与系统设计大赛 14044 基于RT-Thread与边缘计算的弦乐演奏姿态及发力智能评估系统

针对小提琴等弦乐初学者在揉弦时易出现过度发力、肌肉僵硬从而引发慢性劳损的痛点，本项目基于STM32F401主控与RT-Thread实时操作系统，设计了一款软硬件协同的演奏发力智能监测评估系统。系统通过手套端的柔性薄膜压力传感器与惯性传感器，由RT-Thread多线程高频并发采集发力相对强度与手部运动学数据。数据经单片机边缘端进行滤波与特征提取后，实时传输至电脑终端进行图形化可视化显示。系统引入轻量化边缘AI算法，将隐性的肌肉紧绷转化为直观的揉弦频率（Hz）及协同性评分。本系统将抽象的演奏手感转化为科学的可视化反馈，有效帮助初学者建立正确的肌肉记忆，降低练习负担与运动损伤风险。
